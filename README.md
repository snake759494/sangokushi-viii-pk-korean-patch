## 게임 소개 및 대상 버전

「삼국지 VIII」은 코에이의 역사 시뮬레이션 「삼국지」 시리즈 여덟 번째 작품입니다. 군주뿐 아니라 재야·일반 무장·태수·도독·군사 같은 어느 신분의 무장으로도 플레이하며, 평정에서 업무를 제안하거나 명령하고, 무장 사이의 친우·부모·배우자 관계가 이야기를 움직입니다. 전투는 출진 전 군의에서 전술을 정한 뒤 전장 지도에서 부대를 지휘하고, 장수끼리 일기토를 벌입니다. 시나리오는 184년 「황건의 난과 흔들리는 한조」부터 271년 「영웅 집결」까지 있습니다. 「with パワーアップキット」판의 타이틀 메뉴에는 추천 시나리오, 신무장 등록, 무장 편집, 전술 캠페인, 아이템·이벤트 컬렉션, 데이터 인계가 더해져 있습니다.

이 패치는 **PS2 일본판 SLPM-62319 의 BIN/CUE** 에만 적용합니다. PC판이나 다른 기종판에는 쓸 수 없고, 같은 PS2 판이라도 아래 크기·해시가 다르면 적용하지 마세요. 파일 이름보다 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

### Windows 에서 원본 확인

PowerShell 에서 실제 파일 경로를 넣어 실행합니다.

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Sangokushi VIII with Power-Up Kit (Japan).bin'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Sangokushi VIII with Power-Up Kit (Japan).bin'
```

위 표와 다르면 적용을 중단하고 원본 버전 및 파일 상태를 확인하세요. 2,048 바이트 섹터 ISO·CHD·CSO 는 이 패치의 원본이 아닙니다(BIN 은 2,352 바이트 섹터).

### xdelta UI 사용

1. 릴리즈에서 `Sangokushi_VIII_PK_KO_v1.0.2.xdelta` 를 받습니다.
2. xdelta3 패치를 지원하는 도구의 **Apply Patch** 기능을 엽니다.
3. **Patch** 에 xdelta 파일, **Source File** 에 해시가 일치하는 원본 BIN 을 선택합니다.
4. **Output File** 에 원본과 다른 새 파일명, 예를 들어 `Sangokushi VIII with Power-Up Kit (Korean v1.0.2).bin` 을 지정합니다.
5. 적용 완료 후 결과 BIN 의 SHA-256 을 위 표와 비교하고, 아래처럼 `.cue` 를 만듭니다.

호환성을 위해 xdelta 는 2차 압축과 파일 경로 헤더 없이 만들었습니다. UI 명칭은 도구마다 조금 다릅니다. 외부 도구 실행 파일은 이 릴리즈에 포함하지 않습니다. xdelta 자체의 소스와 배포 안내는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Sangokushi VIII with Power-Up Kit (Japan).bin' '.\Sangokushi_VIII_PK_KO_v1.0.2.xdelta' '.\Sangokushi VIII with Power-Up Kit (Korean v1.0.2).bin'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Sangokushi VIII with Power-Up Kit (Korean v1.0.2).bin'
```

원본·패치·결과의 해시를 자동 검사하고 `.cue` 까지 만드는 도구도 있습니다. Python 3 과 xdelta3 실행 파일을 준비한 뒤 저장소 루트에서 다음처럼 사용합니다.

```powershell
python tools/apply_release.py --xdelta '.\xdelta3.exe' --source '.\Sangokushi VIII with Power-Up Kit (Japan).bin' --patch '.\Sangokushi_VIII_PK_KO_v1.0.2.xdelta' --output '.\Sangokushi VIII with Power-Up Kit (Korean v1.0.2).bin'
```

이 도구는 기존 출력 파일을 덮어쓰지 않습니다. 패치 적용 실패나 결과 해시 불일치 시 성공으로 처리하지 않습니다.

### CUE 파일

결과 BIN 과 같은 폴더에 같은 이름의 `.cue` 를 두고, 원본 `.cue` 와 같은 내용에서 `FILE` 줄의 파일 이름만 바꿉니다.

```
FILE "Sangokushi VIII with Power-Up Kit (Korean v1.0.2).bin" BINARY
  TRACK 01 MODE2/2352
    INDEX 01 00:00:00
```

### PCSX2 에서 실행

게임을 완전히 종료한 뒤 새 `.cue` 를 여세요. 패치판은 실행파일과 텍스트 파일의 배치가 원본과 다르므로 **원본판의 세이브 스테이트를 불러오지 마세요.** 이어 하기는 게임 안 메모리카드 저장으로 하세요. 세이브 데이터에는 군주 이름 등이 함께 저장됩니다. 이전 시험 빌드에서 만든 세이브를 불러오면 로드 화면의 이름이 깨져 보였고(시험 중 확인), 원본판 세이브도 같은 이유로 이름이 깨져 보일 것입니다. 새 게임으로 시작하는 것을 권합니다. PS2 브라우저·PCSX2 메모리카드 화면에 보이는 세이브 이름은 본체 글꼴로 그려지므로 일본어 그대로입니다.

## 검증 범위와 제한

- 원본 BIN → xdelta → 결과 BIN 의 SHA-256 이 배포용 완성 BIN 과 일치.
- 저장소의 소스와 번역 데이터만으로 원본 BIN 에서 다시 빌드해 결과 BIN 이 배포판과 바이트 단위로 같음을 확인([validation/rebuild_check.txt](validation/rebuild_check.txt)).
- 빌드 검사: 번역 단위 9,345/9,345, 오류 0(태그 뼈대·줄 수·글자 집합·줄 폭·변수 뒤 조사). 실행파일 문자열 4,245곳 모두 원래 바이트 자리 안(오류 0).
- 대사 속 점프·페이지 위치 인자 1,136개가 모두 원문과 같은 명령을 가리킴.
- `M_MSG.S8` 은 번역 후 1,103 → 1,112 섹터로 커져 원본에서 비어 있던 LBA 46030~47141 로 옮기고 실행파일의 파일 테이블을 함께 고쳤습니다. 다른 파일과 겹치지 않음을 확인.
- CD 섹터(Mode 2 Form 1)의 EDC/ECC 를 다시 계산. 구현은 원본 섹터를 다시 계산해 바이트가 같아지는 것으로 검증. 완성 BIN 에서 바뀐 파일 10개를 다시 읽어 빌드 결과와 같음을 확인.
- 압축 그림 블록은 게임 해제 함수의 모형으로 되풀어 원래 크기·내용을 확인하고 원래 블록 자리 안에 넣음.
- PCSX2 에서 찍은 스크린샷 144장으로 빌드마다 화면을 확인하고 빠진 곳을 고쳤습니다: 타이틀·HELP·튜토리얼, 시대·연대 선택, 무장·세력·도시 선택, 평정, 방침·등용·출진 편성·업무 결정 창, 세이브·로드·환경 설정, 무장 편집, 도시 일람·편집·정보, 연표, 전투 맵과 군의 화면, 일기토, 오프닝 문장([validation/runtime_test.md](validation/runtime_test.md)).

**마지막 빌드에서 고친 위치 인자 보정(대사 앞부분 잘림), 여러 줄 확인창 79개, 부대 상태 표시·업무 판·지도 주 이름은 빌드 검사와 그림 미리보기로만 확인했고 게임 화면으로 다시 보지 못했습니다. 전 시나리오 완주·엔딩·실기 PS2 검증도 하지 않았습니다.** 원문이 종결 매크로 뒤에 의문 조사 `か` 를 두는 곳(약 1,400곳)은 「~습니다?」 꼴이 되어 어색할 수 있습니다.

오류 제보에는 결과 BIN SHA-256, PCSX2 버전, 시나리오·화면·재현 순서와 스크린샷을 적어 주세요. 게임 BIN 이나 추출 바이너리는 이슈에 첨부하지 마세요.

- `work/tools/`: 빌드 도구. 한 번에 빌드(`build_all.py`), 원본 추출(`extract_originals.py`, `bin2iso.py`), 텍스트 컨테이너·토큰(`s8text.py`, `calib_codes.py`, `units.py`), 번역 검사·줄 폭(`validate.py`, `unit_limits.py`), 텍스트·실행파일 빌더와 위치 인자 보정(`build_text.py`, `check_offsets.py`), 실행파일 문자열(`elf_strings.py`, `elf_refs.py`), 이름 데이터(`d_sce.py`, `d_sce_strings.py`, `build_names.py`), 글꼴(`font8.py`, `font_build_ko.py`, `ko_enc.py`), 말투 매크로(`macro_table.py`, `macro_ko.py`, `apply_macros.py`), 그림(`s8gfx_all.py`, `rawgfx.py`, `s9lz.py`, `title/gamedec.py`, `gfx_*.py`), BIN 빌더와 CD 섹터(`build_bin.py`, `cdecc.py`), 대역표(`export_tables.py`).
- `work/trans/`: 빌드 입력 번역 파일(`units.tsv`, `elf_strings.tsv`, `names_officer.tsv`, `dsce_strings.tsv`, 말투 매크로 `macros.tsv`·`ko/macros.tsv`), 줄 폭 표, 코드 인자 표, 번역 규칙.
- `work/font_ko/hangul.tbl`: 한글 ↔ 게임 코드 대응표.
- `translation/`: 사람이 읽는 대역표 TSV.
- `tools/apply_release.py`: 배포 패치 적용·해시 검사·CUE 생성.
- `docs/`, `validation/`: 기술 설명, 재빌드 절차, 글꼴 출처, 검증 기록.
