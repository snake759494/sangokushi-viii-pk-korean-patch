## v1.0.1 제보 반영 (2026-09-23)

| 제보 (팬 카페 스크린샷) | 확인·조치 |
| --- | --- |
| 지도 범례 「도로 종류·보통·하천·산악」 한글이 깨짐 | v1.0 이 팔레트를 몰라 색 번호를 추정해 그린 탓. 게임 팔레트(G_SYSTEM 0x8400)를 찾아, 그 팔레트로 원본 범례가 정확히 재현되는 것(흰 글자, 군단 색 견본, 회색·청록·주황 선)을 확인한 뒤 원본 글자와 같은 회색 단계 색으로 다시 그림 |
| 지도의 세력 색이 모두 같아 보임 (도시 칸이 모두 노란색) | 그림을 고치기 전 빌드의 스크린샷에서도 도시 선택 화면은 노란색(고를 수 있는 도시)·회색(고를 수 없는 도시)이었고, 같은 빌드의 주 선택 지도는 세력 색으로 나옴 → 원래 동작으로 판단. 실행파일에서 번역한 문자열 중 색 데이터(RGBA)로 보이는 것이 없음도 확인 |

같은 방식으로 다른 그림 글자의 팔레트도 다시 확인했습니다. 전략 지도 주 이름(G_EMTMP)은 실제 팔레트(블록 14 의 0번)로 그려도 원본과 같은 크림색 글씨·어두운 그림자로 나옵니다.

- 여러 줄 확인창 79개 (세이브·로드·무장 편집·설치·전술 캠페인 이력 등)

전 시나리오 완주·엔딩, 실기 PS2 는 확인하지 않았습니다.
