# 삼국지 VIII PK (PS2) 한글화 번역 규칙

**기계번역 금지.** 번역기·자동 치환을 쓰지 않는다. 문장마다 상황과 화자를 보고 사람이 직접 옮긴다.
원문의 정보(인물·사건·수치·조건)는 빼거나 더하지 않는다.

## 0. 번역 파일 형식

`work/trans/units.tsv` 는 `group / entry / jp / ko` 네 칸이다. `jp` 를 읽고 `ko` 만 채운다.

원문은 게임 스크립트를 태그로 적은 것이다. **다음 기호는 뜻과 순서를 지켜 그대로 남긴다.**

| 기호 | 뜻 | 규칙 |
| --- | --- | --- |
| `⏎` | 줄 바꿈(`@R`) | 개수를 원문과 **똑같이** 유지. 화면이 이 단위로 넘어간다 |
| `‖` | 문자열 끝(NUL) | 개수·자리를 원문과 **똑같이** 유지 |
| `{XXXX}` | 제어 코드 | 지우거나 새로 만들지 않는다. 순서도 유지 |
| `{XXXX:n}` `{XXXX:n,m}` | 인자가 있는 코드 | 숫자까지 그대로 |
| `N` | 이름·숫자가 들어갈 자리 | 앞의 `{00xx}` 코드와 한 쌍이다. 지우지 않는다 |

**즉, `ko` 는 `jp` 에서 일본어 글자만 한국어로 바꾼 것이어야 한다.** 태그·`⏎`·`‖`·`N` 은 손대지 않는다.
한국어 어순 때문에 낱말 순서를 바꿔야 하면, `‖` 로 나뉜 같은 줄(`⏎` 사이) 안에서만 옮긴다.

## 1. 기술 제약 (어기면 빌드가 거부된다)

| 항목 | 규칙 |
| --- | --- |
| 한글 | **KS X 1001 완성형 2,350자만**. `뷁 똠 햏 쀍` 같은 완성형 밖 글자는 쓸 수 없다 |
| 한자·가나 | 쓰지 않는다. 한자 자리를 한글로 덮었으므로 한자를 쓰면 엉뚱한 한글이 나온다. 괄호 속 한자 병기도 안 된다 |
| 문장부호 | 반각 `, . ! ? : ( ) ~ -` 를 쓴다. 일본식 `、 。` 는 쓰지 않는다. `「」 『』 ・ ＜＞ 【】 ／ …… ○ × △ →` 는 원문과 같은 자리라면 그대로 써도 된다 |
| 숫자 | 반각 `1 2 3`. 원문이 전각 `１２３` 이어도 반각으로 쓴다 |
| 띄어쓰기 | 한글 맞춤법대로. 들여쓰기는 원문처럼 전각 공백 `　` |
| 줄 폭 | 아래 3장 |

### 1.1 `N` 뒤의 조사

`N` 자리에는 게임 중에 이름·지명·숫자가 들어간다. 받침을 알 수 없으므로
**`N` 바로 뒤에 받침에 따라 바뀌는 조사를 붙이지 않는다.**
금지: `을 를 이 가 은 는 과 와 로 으로 나 이나 야 아 여 라 란`. `을(를)` 병기도 금지.

쓸 수 있는 방법
1. 받침과 무관한 조사: `의 에 에게 에서 께 께서 도 만 까지 부터 한테 보다 처럼 같이`
2. 말을 덧붙여 받침을 고정: `N 장군이`, `N 님은`, `N 군은`, `N 쪽은`, `N 성을`, `N 병법을`
3. 어순을 바꾼다: `N が討死しました` → `N 장군이 전사했습니다`, 또는 `전사: N`
4. 쉼표로 부르기: `N, 각오하라!`
5. 시스템 메시지는 명사형으로: `N 에게 수여`, `N 민심 상승`

## 2. 말투 매크로 (8PK 에서 가장 중요)

이 게임은 **한 문장을 「어간 + 말투 매크로」로 짜 놓고, 화자(군주·신하·여성·노장·거친 무장)에 따라
매크로가 다른 어미로 펴진다.** 한국어도 교착어라 같은 구조를 그대로 살린다.
매크로의 한국어는 `work/trans/ko/macros.tsv` 에 이미 정해져 있다(표는 아래 2.2).

### 2.1 어간 계약 — 반드시 지킬 것

* **어미 매크로 바로 앞의 어간은 받침으로 끝나게 쓴다.** (`았 었 겠 ㅆ 있 없 같 ...`)
  그래야 `습니다 / 다 / 네 / 소 / 어요` 가 모두 바르게 붙는다.
  * `予測が当た{05D1}{05AA}` → `예측이 맞았` + `습니다` + `군요`  → 「예측이 맞았습니다」
  * `評定を始め{05C2}` → `평정을 시작하겠` + `습니다`/`다`
  * `到着し{05CD}` → `도착했` + `습니다`/`다`
  * `でき{05AF}` → `할 수 없` + `습니다`/`다`
* **체언에 붙는 매크로**(`{0576}` です/だ 등)는 앞에 명사를 둔다. 한국어는 `입니다/이다` 라서 받침이 있든 없든 붙는다.
* **낱말째 펴지는 매크로**(`{05B9}` 思います → 생각합니다 등)는 앞에 그 낱말을 또 쓰지 않는다.
  `〜と{05B9}` → `~라고` + `생각합니다`
* 매크로를 지우고 어미를 어간에 붙여 쓰면 안 된다. 매크로가 사라지면 말투가 전부 같아진다.

## 3. 줄 폭

폭은 반각 단위로 센다(한글·전각 2, 반각·공백 1, 태그 0, `N` 은 8로 본다).
`⏎` 로 나뉜 **줄마다** 그 그룹의 한계를 넘으면 안 된다. 한계는 `work/trans/group_limits.tsv`
(그 그룹 원문의 가장 긴 줄, 최소 24). 작업 파일 머리에 `[폭 28]` 처럼 적혀 있다.

* `⏎` 개수는 원문과 같아야 한다. 줄을 늘리거나 줄이지 않는다.
* 한 줄이 넘치면 조사·군더더기를 줄이고, 같은 줄 안에서 말을 다시 짠다. 정보는 빼지 않는다.
* 어절(띄어쓰기) 단위로만 줄을 바꾼다.

## 4. 문체

| 원문 | 한국어 |
| --- | --- |
| 메뉴 항목 (`〜を始める`, `〜する`) | 명사형 — 新しくゲームを始める → 새 게임 시작 |
| 하단 도움말 (`〜します`) | 합쇼체 — 새 게임을 시작합니다 |
| 도움말·용어 설명 (です・ます) | 합쇼체 |
| 시나리오 개요 (だ・である) | 해라체 — ~한다, ~했다 |
| 무장 열전·연표 | 해라체 서술 |
| 확인 창 (`よろしいですか？`) | ~하시겠습니까? |
| 알림 (`〜しました`) | ~했습니다 (좁으면 명사형 `~ 완료`) |
| 승리 조건 등 목록 | 명사형·해라체 |

인물 대사의 말투는 **매크로가 정한다.** 어간은 말투에 치우치지 않게 중립으로 쓴다.
매크로 없이 통째로 쓰인 대사는 원문 어미로 말투를 판단한다
(です·ます → 합쇼체, だ·ぞ → 하게체·해라체, ござる·じゃ → 하오체, わ·ね·かしら → 해요체,
거친 말(〜ぜ·俺様) → 거친 반말).

호칭: 殿(군주에게) → 주공, 陛下 → 폐하, 〇〇殿 → 〇〇 님, 〇〇様 → 〇〇 님, 兄者/兄貴 → 형님,
父上 → 아버님, 母上 → 어머님, 我が君 → 주군, 貴様 → 네놈, 拙者/それがし → 소장, 余 → 짐.
